# LifeBook V1

LifeBook is a web application that transforms your WhatsApp chat logs into an evidence-bound narrative story book or memoir chapter.

## Features
- **WhatsApp Chat Processing**: Upload chat history text files.
- **AI-Powered Narration**: Uses an intelligence engine to format and structure chat history chronologically.
- **Evidence-Bound Stories**: Preserves the true context of conversations into readable chapters.

## Tech Stack
- **Backend**: FastAPI (Python)
- **Deployment**: Vercel
